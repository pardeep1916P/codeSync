# Naming Conventions

## Purpose & Scope
Maintains readability across extension contexts.

## Checklists
- [ ] Files names are in camelCase or kebab-case.
- [ ] Components are PascalCase.
- [ ] Local storage keys are prefixed (e.g. sub_, _oauthCache).
