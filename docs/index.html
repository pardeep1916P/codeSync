Architecture & Standards

Built with Zero Compromise

Engineered as a robust, privacy-first Manifest V3 browser extension adhering to strict invariants.

Sub-10ms Enqueue

MAIN-world network interceptor captures accepted submissions instantly without slowing down problem solving or page responsiveness.

Authentic Timestamps

Sets both author and committer dates to the authentic problem solve moment, accurately populating your GitHub contribution graph.

AES-GCM Encryption

GitHub tokens are encrypted at rest with 256-bit AES-GCM via the Web Crypto API. No external servers or third-party databases ever see your data.

Multi-Platform Aggregator

Unified stats dashboard records real-time problem metrics across all supported platforms directly into your repository's stats.json.
