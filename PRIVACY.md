# CodeSync Privacy Policy

**Effective Date:** August 7, 2026

CodeSync ("we", "our", or "the extension") is committed to protecting your privacy and ensuring transparent processing of your data.

## 1. Single Purpose
CodeSync has a single, focused purpose: automatically synchronizing your accepted LeetCode problem solutions directly to your personal GitHub repository.

## 2. Information Processed
CodeSync processes only the minimal data necessary to provide its core service:
- **Authentication Credentials**: Your GitHub Personal Access Token (PAT) or OAuth access token, which is stored locally inside your browser's secure extension storage (`chrome.storage.local`).
- **Submission Details**: Information regarding your accepted LeetCode submissions (problem title, difficulty, code content, programming language, and submission ID) solely for committing files to your designated GitHub repository.

## 3. Storage & Data Security
- All tokens, target repository selections, and queue states remain stored locally on your device.
- CodeSync does NOT operate any external servers to collect, store, track, or analyze your credentials or solution data.
- All network requests occur directly over encrypted HTTPS connections between your browser, LeetCode (`https://leetcode.com`), and GitHub (`https://api.github.com`).

## 4. Data Sharing & Privacy Disclosures
- CodeSync does **NOT** sell, rent, or share user data with third parties.
- CodeSync does **NOT** use user data for advertising, tracking, profiling, or creditworthiness evaluation.
